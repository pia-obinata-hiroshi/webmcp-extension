# AI-DLC 学習ルール

パイプラインの修正・レビュー指摘のうち、人間が承認した永続ルール。
後続タスクのサブエージェントはこのファイルを遵守する。
- レガシー・外部名前空間のグローバル検出はプロトタイプチェーンを辿る in 演算子ではなく own-property チェック（Object.hasOwn 相当）で行い、検出対象が getter/Proxy を持ち得る場合は検証と書き込みの間の再入を考慮する（review/blackhat / 2026-11-09）
- モジュール評価順序に依存する import は side-effect と named の二重記述を避け一本化し、import organizer の再ソートで順序が壊れない構造にする（review/typist / 2026-11-09）
- 外部オブジェクトの形状検出（ファクトリ認定等）は単一メソッドの存在だけでなく、用途固有の複数メンバで認定し誤検出を防ぐ（review/blackhat / 2026-11-09）
- 副作用のある呼び出しのリトライでは catch 対象を目的の失敗のみに限定し、成功後の後処理が投げるエラーを誤認しないよう try 範囲を分離する（review/blackhat,typist / 2026-11-09）
